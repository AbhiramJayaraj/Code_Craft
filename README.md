# Edavappathi — Bottled First Rain (Card Craft Challenge)

This repository contains my submission for the FOCES CEC Card Craft Challenge. 

## 🌧️ The Concept: Edavappathi
*Distilled from Kerala's opening downpour. Handle gently — it still remembers thunder.*

"Edavappathi" is the Malayalam term for the southwest monsoon in Kerala. This product card imagines a world where the very first rain of the monsoon is captured, bottled, and sold as an artisanal, limited-edition elixir. The design combines rustic, earthy tones with a mystical, stormy ambiance.

## ✨ Key Design Features (Pure HTML & CSS)
- **CSS Art Jar:** The entire jar, liquid, lid, and bubbles are constructed entirely out of CSS shapes, gradients, and box-shadows. No external images are used!
- **Liquid Physics Simulation:** Using overlapping pseudo-elements with `border-radius` and custom `@keyframes` to create a realistic, endlessly waving liquid effect inside the jar.
- **Dynamic CSS Rain:** A looping linear-gradient background creates a subtle, falling rain effect behind the main content.
- **Micro-Animations:** Bubbles slowly rise through the liquid, a shine effect glides across the jar on hover, and the card itself features an elegant 3D tilt effect on hover.
- **Typography & Details:** Features Malayalam text on a masking-tape label, a golden wax-seal price tag, and distinct typography pairings (Fraunces & Space Mono) to emphasize the artisanal, limited-edition feel.
- **Strictly 400x500 Canvas:** Adheres to the exact canvas dimensions using container queries (`container-type: inline-size`) and `cqw` units, ensuring the 400x500 ratio scales fluidly while retaining its exact composition on any screen size.

## 🚀 How to View
